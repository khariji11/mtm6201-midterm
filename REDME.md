# LaslesVPN – MTM6201 Midterm Project

## Project Description

This project is a responsive website created for the MTM6201 Advanced Web Design midterm assignment at Algonquin College.

The goal of this project is to recreate the LaslesVPN landing page design using HTML and CSS, based on the provided Figma reference.

## Pages

- Home (`index.html`)
- Pricing (`pricing.html`)
- About (`about.html`)

## Features

- Responsive design for desktop, tablet, and mobile
- Responsive images using the HTML picture element
- CSS Grid and Flexbox layouts
- CSS transitions and animations
- Accessible navigation and semantic HTML

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub
- GitHub Pages
